# Preserved migration input

These are exact copies of the pre-migration routed-action test files, including
uncommitted user edits present when the native Share migration began. They are
retained for comparison and recovery and are not part of the current test suite.

The native tests in ../../tests exercise current production APIs. The old files
reference share-coin redemption, phantom share types, foreign-cap acceptance,
and unrestricted principal fixtures that no longer describe the protocol.
